# Список отложенных вещей.

## Команда тулчейна `pmem-migrate`.

Содержит подкоманды, каждая из которых работает на обновленном конфиге и требует указания старых
значений для перестройки фиксированной области pmem.

### `lba` для смены размера хардверного LBA при смене накопителя.

Режим работы `pmem` для WAL-а требует перестройки буферов в NVDIMM при переходе на накопитель с
другим LBA.

Выглядит как

```shell
mpy6a pmem-migrate lba --old-lba 4Kib
```

## `cpu` при перенастройке количества индексов (смена CPU, осознанное решение о расширении).

Работает ТОЛЬКО в сторону увеличения. Уменьшение потребует кластерной миграции данных.

```shell
mpy6a pmem-migrate cpu --old-index-count M
```

## `replication` при изменении фактора репликации.

```shell
mpy6a pmem-migrate replication --old-factor F
```
