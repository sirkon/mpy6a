# Рефакторинг логики работы со снапшотами.

На данный момент логика управления снапшотами размазана по файлам index.zig и elephant.zig (т.е. по потокам индексов и
слонов).

Я хочу чтобы ты спланировал рефакторинг текущего состояния на следующий:

1. Сама логика будет находиться в ./src/snapshot.zig
2. В index.zig и elephant.zig используются функции и методы из snapshot.zig
3. При необходимости логику слонов и индексов можно "запечатать" в объектах, чтобы граф вызовов мог безболезненно гулять
   снапшот -> индекс -> снапшот -> .... Т.е. это выражение конечного автомата на языке API.

В последнем пункте виртуализации не требуется. Если хочется тестов, можно использовать anytype.
